# Harsh Karn - Portfolio

Welcome to my personal portfolio repository! This is a modern, high-performance web application built to showcase my projects, skills, and professional experience across Full Stack Development, AI Engineering, and Data Analytics.

## 🚀 Live Demo
Visit the live portfolio: [https://harsh-karn.vercel.app](https://harsh-karn.vercel.app) *(Update with your actual link if different)*

## 🛠 Tech Stack
This portfolio is built with modern web technologies focused on performance and fluid user experiences:
- **Framework:** Next.js (App Router)
- **Language:** JavaScript / React
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** React Icons
- **Deployment:** Vercel

## ✨ Key Features
- **Dynamic Preloader:** A custom scrolling marquee preloader built with Framer Motion.
- **Glassmorphism UI:** Sleek, translucent navbar and cards for a modern aesthetic.
- **Project Showcase:** A dynamic grid of projects filterable by "Featured" status, reading directly from a centralized data file.
- **Fully Responsive:** Carefully crafted to look perfect on mobile, tablet, and desktop devices.
- **API Integrated Contact Form:** Built-in Next.js Route Handler for the contact form powered by NodeMailer.

## 💻 Local Development

First, clone the repository and install dependencies:

```bash
git clone https://github.com/Harsh-karn/portfolio.git
cd portfolio
npm install
```

Next, set up your environment variables by creating a `.env.local` file in the root directory:
```env
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_gmail_app_password
```

Finally, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
